# P3-T14 — Presigned PUT upload
P3 · mode A · Should · est 3h · agreed · 2026-11-19

**Why:** `POST /medias/upload` streams up to 10 MB through an api task (`MediaService.upload`), against "API never streams bytes" (`02-tech-stack.md:32`).
**Value:** browser uploads go straight to S3 → unblocks the P5 frontend → M1; the scale-to-zero api stays small (ADR-0013).

## Concepts
- **Signed headers:** the client can't PUT another type or size than it declared: S3 answers 403.
- **The key is the capability:** `channel/{id}/…` authorises access, so a SEND must use a key of its own channel.
- **Validate before signing:** the `MediaKind` type/size checks run before any port call.

## Done when
1. A member POSTs `/api/v1/medias/presign-upload {channelId, contentType, size}` → 200 `{url, key, expiresAt}`. The key is for that channel, its extension comes from the type, and the TTL is 5 min.
2. A non-member → 403 `MEMBER_404`, nothing signed.
3. Bad type, `size ≤ 0` or over the limit → the existing 4xx errors, nothing signed. Exact limits pass.
4. The PUT signs `content-type`, `content-length` and `if-none-match: *`.
5. A media SEND with a malformed or other-channel key → `InvalidObjectKeyException`, no seq bump.
6. `/upload` still works, is `deprecated` in OpenAPI and sends a `Deprecation` header.
- **Out of scope:** checking the object exists at SEND, orphan cleanup (P6), presign rate limit, bucket CORS, narrowing IAM to `channel/*`, GET `nosniff` (P5).
- **Tests:** `MediaServiceTest` (1–3), `S3StorageAdapterTest` (4), `MessageServiceTest$MediaKeys` (5), `MediaControllerTest` (1, 6), `MediaControllerIT` (2, 6).

## Decisions
| Question | Answer | Source |
|---|---|---|
| Size enforcement | PUT with signed `Content-Length`, not a POST policy | user; SDK presigner |
| Key check at SEND | Shape + channel match, no S3 call | user; lessons #9 |
| Overwrite after SEND | `If-None-Match: *`: one write per key | security review |
| Non-member status | 403, like `/upload` and `/presigned-url` | `HttpErrorMapper` |
| PUT TTL | 5 min (GET stays 10) | user |
| Happy-path test | `@WebMvcTest`: CI has no AWS creds to sign with | `AbstractIntegrationTest` |
