# P2-T03 — data stack (Aurora, media bucket, secrets)
P2 · mode C · Must · est 3–4 h · done · 2026-10-17

**Why:** `infra/stacks/` has only `bootstrap` + `network`; the account has no DB (`describe-db-clusters` → `[]`) and no `devcool-media` (HeadBucket 404), yet `application-ecs.properties:3-5,17` and `application.properties:27-28` expect an RDS secret, a bucket and JWT secrets → P2-T04's migrate task has nothing to connect to, so M1 is blocked.
**Value:** the stateful layer of the walking skeleton → M1. Unblocks P2-T04 (task def `secrets`, task role S3), P2-T09 (hibernate applies `data`), P4-T05 (Valkey toggle here), P8 (pgvector, [ADR-0009](../../plans/architecture/adr/0009-aurora-postgres-pgvector.md)).

## Concepts
- **RDS-managed master secret:** without: a `random_password` lands in state, which `gha-plan` can read. With: `manage_master_user_password = true`; Terraform knows only the ARN, and the task def injects `username`/`password`. Read: [ref 05](../../references/05-postgresql-and-data-access.md) §Aurora.
- **Secret values outside Terraform:** without: `aws_secretsmanager_secret_version` for JWT → every PR's `infra-plan` fails AccessDenied on `GetSecretValue`. With: Terraform owns the empty containers; the values are set once out of band. Read: [bootstrap review #4](../../improvements/2026-10-14-bootstrap-review-improvements.md#p2-t03--data-stack).
- **Auto-pause at 0 ACU:** without: a 0.5 ACU floor = $0.06/h ≈ $43/month idle, over the whole budget. With: no connections for 600 s → $0 compute; the first request waits for resume, covered by Hikari 60 s (`application-ecs.properties:8`). Read: ref 05 §Aurora.
- **`prevent_destroy` on a nightly-applied stack:** without: a bad var in the unattended hibernate apply replaces the cluster and every message is gone. With: the plan errors before AWS is touched. Read: [ADR-0013](../../plans/architecture/adr/0013-dev-cost-envelope-under-20-usd.md) §Consequences, [ref 08](../../references/08-terraform-iac.md) §lifecycle.

## Done when
1. Given `network` applied, when `data` applies, then Aurora PG16 (1 `db.serverless` writer, 0–4 ACU, pause 600 s) runs in private subnets behind `sg-aurora`, encrypted, with an RDS-managed secret rotating every 365 days.
2. The media bucket (`var.media_bucket_name`) blocks public access, has SSE and a TLS-only policy, and aborts incomplete multipart uploads.
3. Two JWT secrets (access, refresh) exist with values set out of band (`infra/README.md` runbook); `terraform state pull` contains no secret value.
4. SSM `/devcool/dev/data/*` String params exist: endpoint, port, db name, master secret ARN, bucket name/ARN, both JWT secret ARNs.
5. A 2nd `plan` shows no changes; `plan -destroy` fails on `prevent_destroy`; the cluster has `deletion_protection` and takes a final snapshot.
6. After 10+ min idle, CloudWatch `ServerlessDatabaseCapacity` = 0.
- **Out of scope:** task def/task role/DB connectivity (P2-T04), Valkey (P4-T05), SNS/SQS (P6), `CREATE EXTENSION vector` (P8 Flyway), reader/prod (ADR-0013), `infra-plan` workflow (P2-T08).
- **Tests:** CI infra job (fmt, validate, tflint, Trivy) · `aws-architect` plan review · apply → re-plan = 0 · `plan -destroy` errors · `grep` for no `secret_version`/SecureString · pause metric.
- **Files:** `infra/stacks/data/*.tf`, `infra/envs/dev.tfvars`, `infra/README.md`, bootstrap review (#4, #3b closed), phase file tick.
## Decisions
| Question | Answer | Source |
|---|---|---|
| Capacity / pause | 0–4 ACU, 600 s; engine ≥ 16.3 (auto-pause needs it, verify at impl) | ADR-0009 |
| Encryption keys | AWS-managed; inline `#trivy:ignore` + reason | ADR-0013, `bootstrap/state.tf:21` |
| Enhanced monitoring | Off → #3b PassRole not needed | ADR-0013, review #3b |
| Cross-stack values | SSM `String` only | `network/ssm.tf:1-2` |
| Bucket name / versioning | `devcool-media` via var (globally free today); versioning off, keys are uuids | `application-ecs.properties:17` |
| JWT secret values | Out of band (`put-secret-value`); Terraform creates containers only | user; review #4 |
| JWT secret shape | Two secrets, access and refresh, revocable independently | user |
| RDS secret rotation | Every 365 days; nightly hibernate restarts tasks anyway | user; P2-T05 carry-over |
| Aurora guard | `prevent_destroy` + `deletion_protection` + final snapshot; raw resources, since a module can't take `prevent_destroy` | user; ADR-0013 |
