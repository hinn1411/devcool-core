# P3-T06 — Edit message (PATCH /messages/{id})
P3 · mode A · Must · est 3h · done · 2026-11-11

**Why:** messages could never change: no edit use case, `MessageEntity` didn't map V4's `version`, and history had no `version` for a client to send back.
**Value:** phase goal "Edit/delete". Unblocks P4-T04 (WS `EDIT` → `MESSAGE_UPDATED`) and P5-T07 (edit UI).

## Concepts
- **Client-version CAS:** `UPDATE … WHERE id=? AND version=:expected` → 0 rows → 409. One statement covers the stale client (common) and the race (rare); `@Version` load→save misses the stale client. Ref 05 § Optimistic concurrency.
- **No oracle:** missing / deleted / non-member → the same 404; member but not the sender → 403.
- **Injected Clock:** the 24h boundary is testable at 24h−1s and 24h (`ClockConfig`).

## Done when
1. Sender + current `version` + < 24h → 200, content replaced, `version+1`, `editedTime=now(clock)`.
2. `version` ≠ current → 409, row unchanged (ITs: stale client; 20 concurrent edits → 1 wins).
3. `createdTime + 24h ≤ now` → 403 `MESSAGE_EDIT_WINDOW_CLOSED`; 24h−1s → 200.
4. IMAGE/VIDEO → 400; content rules from P3-T15 (`MessageContentPolicy`).
5. Same content + current version → 200, no bump, `editedTime` unchanged.
6. Member not sender → 403; non-member / unknown / deleted → 404.
7. History items carry `version` and `editedTime`.
8. `content` and `version` required → 4xx when missing.
- **Out of scope:** WS `EDIT` (P4-T04), edit history, changing contentType, delete (P3-T07).
- **Check order:** load → member (404) → sender (403) → type → window (403) → content → version → no-op → CAS update (409).

## Decisions
| Question | Answer | Source |
|---|---|---|
| Version transport | Body field `version` (shared with P4 WS `EDIT`) | user |
| Window closed | 403 `MESSAGE_EDIT_WINDOW_CLOSED`; 409 only for versions | user |
| Editable fields | `content` only, required | user; ADR-0014 noted |
| Unchanged content | No-op 200, no bump; version checked first | user |
| Lock style | Conditional UPDATE, not `@Version`; column `insertable/updatable=false` so no entity save can rewrite it | phase notes; review |
