# P4-T02 — Protocol v2 envelope, dispatcher, per-frame errors
P4 · mode B · Must · est 5–6 h · done · 2026-11-26

**Why:** v1 has no `reqId` (`SendMessageAction.java:42` replies `ERROR{clientMsgId:null}`), its errors are free text, and any non-domain exception closes the socket with 1011 (`learning/04` §7).
**Value:** Stage 1 hardening (`learning/10` §7) → M2. Unblocks T03, T04, T09, T12, T13, T14, T17, P5-T06, P8 `ASK`.

## Concepts
- **reqId correlation:** without: 2 SENDs in flight, one fails → `ERROR{null}`. With: `NACK{reqId}` marks only that one. Read: ADR-0005 drivers.
- **NACK codes:** `FORBIDDEN` → drop the channel; `INTERNAL` → retry the same `clientMsgId`. Read: `ws-protocol` skill.
- **Catch-all boundary:** an NPE on SEND → `NACK INTERNAL`, not 1011; other subscriptions keep flowing. Read: `learning/04` §7.
- **Tolerant reader + version gate:** unknown fields ignored; unknown `v` → 4400. Read: ADR-0005 rules 4–5.

## Done when
1. A v2 `SUBSCRIBE`/`UNSUBSCRIBE`/`SEND` with a `reqId` → one `ACK` with that `reqId`; SEND ACK = `{clientMsgId, messageId, seq, createdTime}`.
2. An unknown or not-yet-built type → `NACK{UNSUPPORTED}`; unknown fields are ignored.
3. A bad payload (no `channelId`, bad `clientMsgId`/`contentType`) → `NACK{INVALID}` with the `reqId`.
4. A reply-needing frame without `reqId` → `NACK{INVALID, reqId:null}`; the action does not run.
5. `DomainException` → `NACK{mapped code, message: domain code}`; a non-member `SUBSCRIBE` → `FORBIDDEN`.
6. Any `RuntimeException` → `NACK{INTERNAL}`, logged; the next frame still works.
7. Unparseable JSON → `ERROR{INVALID}`; the socket stays open.
8. `v` missing or 1 + flag on → v1 path; flag off or other `v` → close 4400.
9. Latest frame v2 → `MESSAGE_NEW` pushes; v1 → `MessagePush`.
- **Out of scope:** PING/PONG (T03), new types (T04/T09/T12), rate limit + frame size (T13), metrics (T15), origin allowlist (T06), v1 removal (T17).
- **Tests:** `FrameDispatcherTest` (1–7), `NackCodeMapperTest`, `ChatHandlerTest` (8), `SessionEmitterAdapterTest` (9), `WsProtocolV2IT` (1, 5, 6, 9); `AbstractWsIT` on v2, `BigintIdsIT` stays v1.
- **Invariants / authz:** no frame error closes the socket; commit → ACK → publish; membership checks stay in the services.
