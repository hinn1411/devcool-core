## Concepts
- **Fitness function:** without: an IDE auto-imports `JwtUtils` into a service and review misses it (learning/03 §2). With: `./mvnw test` fails and names the class and the dependency. Read: ref 01, "Architecture fitness functions".
- **Static calls are dependencies:** without: "every collaborator is a port" looks true, because `JwtUtils.buildRefreshToken(...)` isn't in the constructor. With: ArchUnit reads bytecode, so static calls count. Read: learning/03 §2.
- **Shared state between adapters means a port is missing:** without: the emitter can't move to Valkey (P4) without the inbound `WsSessionStore`. With: the coupling is explicit: one transport, one adapter package. Read: learning/03 §3.
- **Red first:** the suite must fail on today's master before the fixes. That proves every rule can fail.
