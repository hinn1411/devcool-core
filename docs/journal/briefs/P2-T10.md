# P2-T10 — CI infra job: fmt, validate, tflint, trivy
P2 · mode C · Must · est 2.5h · agreed · 2026-10-14

**Why:** `.github/workflows/ci.yml:8` has only the backend job, so `infra/` changes merge unchecked; errors surface at a local `plan`/`apply`, or from P2-T08 on in a job holding AWS credentials.
**Value:** broken or insecure HCL fails on the PR with no AWS access → protects P2-T02…T09 (~40 resources) and M1's "plan → review → apply"; P2-T08's `infra-plan` only sees code that passed. Infra-only PRs also stop paying for the Maven + Sonar build.

## Concepts
- **Job-level path filter:** without: a separate workflow with `paths: infra/**` made required → a backend-only PR waits forever on "Expected". With: a `changes` job + `if:` → a skipped job still reports and passes. Read: [ref 09](../../references/09-cicd-and-supply-chain.md) §Concepts (path filters).
- **Layered static checks:** `validate` = HCL/schema; `tflint` + AWS ruleset = valid HCL but wrong for AWS (`instance_type = "t5.micro"`, deprecated args); `trivy config` = insecure config (public bucket, `*` IAM). Read: [ref 08](../../references/08-terraform-iac.md) Self-check.
- **`init -backend=false`:** without: CI `init` reaches for the S3 backend → needs AWS credentials. With: providers only, no backend, no credentials.
- **Suppressions as documented decisions:** without: Trivy flags SSE-S3 → CI stays red, or the threshold drops and hides the next real HIGH. With: an inline ignore citing the P2-T01 decision; any new HIGH still fails.

## Done when
1. A PR touching `infra/**`, `ci.yml`, `ci-changes.yml` or `ci-infra.yml` runs the `infra` job; any other PR shows it **skipped**, not pending.
2. A PR touching backend paths (`src/**`, `pom.xml`, `mvnw*`, `.mvn/**`, `spotbugs-exclude.xml`, `ci{,-changes,-backend}.yml`) runs the backend job; an infra- or docs-only PR shows it skipped. Push to `master` behaves the same.
3. `infra` fails on any of: unformatted HCL, `validate` errors in any stack/module, tflint issues, unsuppressed Trivy HIGH/CRITICAL.
4. Current `bootstrap` passes: each existing finding is fixed or suppressed inline with a one-line reason.
- **Out of scope:** `terraform plan` in CI (needs OIDC, P2-T08), frontend job (P5), making the checks required in the ruleset (P2-T08, review #1).
- **Tests:** throwaway PR showing each failure once (misformatted file, `t5.micro`, public bucket); a backend-only PR (infra skipped); an infra-only PR (backend skipped).
- **Files:** `.github/workflows/ci{,-changes,-backend,-infra}.yml`, `infra/.tflint.hcl`, inline ignores in `infra/stacks/bootstrap/*.tf`, CLAUDE.md "CI Pipeline" (now path-filtered).
