# P2-T01 — Bootstrap: state bucket, GitHub OIDC roles, ECR
P2 · mode C · Must · est 3h · done · 2026-10-13

**Why:** bootstrap state lives only on one laptop (`infra/stacks/bootstrap/versions.tf:11`), CI has no way into AWS without static keys, and there is no registry → P2-T08 can't exist and the M1 DoD "no AWS keys in GitHub" can't be met.
**Value:** shared, locked state for every stack + keyless CI + image registry → M1 (`git push` → ECS). Unblocks P2-T02…T07 (backend), P2-T08 (roles, ECR), P2-T09 (`gha-deploy`).

## Concepts
- **Remote state + `use_lockfile`:** without: you and CI both apply `network` from separate state → two NATs, diverged state. With: one `devcool/<env>/<stack>.tfstate` in S3; the second apply waits on the lock. Read: [ref 08](../../references/08-terraform-iac.md) §Concepts, [learning 17](../../learning/17-terraform-in-devcool.md) §3.1.
- **Chicken-and-egg:** bootstrap creates the bucket, so it starts on local state and moves in with `terraform init -migrate-state`. Read: learning 17 §3.1.
- **OIDC federation:** without: `AWS_SECRET_ACCESS_KEY` in repo secrets; one leak is valid forever. With: STS swaps a per-job GitHub token for ~1h credentials. Read: [ref 09](../../references/09-cicd-and-supply-chain.md) §Concepts.
- **`sub` pinning:** without: trust `repo:hinn1411/*` → a PR branch assumes `gha-deploy` and applies. With: deploy trusts `ref:refs/heads/master` only; plan trusts `pull_request`. Read: learning 17 §4.2, §6.11.

## Done when
1. `terraform plan` on bootstrap → no changes; state at `devcool/shared/bootstrap.tfstate` in the bucket; no local tfstate left.
2. State bucket: versioning, SSE-S3, all 4 public-access blocks, TLS-only bucket policy, `prevent_destroy`.
3. Only a job in the `aws-deploy` environment (master only) assumes `gha-deploy`; a PR or other master job (e.g. `@claude`) can't. A PR job assumes `gha-plan`, which can't write anything except `*.tflock`.
4. ECR `devcool`: scan on push, IMMUTABLE tags, lifecycle keeps the last 20 images.
- **Out of scope:** plan/apply/deploy workflows (P2-T08), env `backend.hcl` (P2-T02), per-env GitHub environments (P2-T08 / budget ADR), CI fmt/tflint (P2-T10).
- **Tests:** no-op `plan`; `aws s3api get-bucket-{versioning,encryption}`, `get-public-access-block`; `aws ecr get-lifecycle-policy`; `oidc-test.yml` run on a PR (plan ✓, deploy ✗) and on `master` (deploy ✓), then deleted.
- **Files:** `infra/stacks/bootstrap/{state,oidc,ecr}.tf`, edits to `versions.tf`, `variables.tf`, `outputs.tf`; temporary `.github/workflows/oidc-test.yml`.
- **Invariants:** no access keys anywhere; role ARNs are outputs (repo variables later), not secrets; IAM exceptions are commented in code.
