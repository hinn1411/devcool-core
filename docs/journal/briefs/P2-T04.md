# P2-T04 — `ecs-service` module + `app` stack
P2 · mode C · Must · est 9h · agreed · 2026-10-19

**Why:** `infra/stacks/` has no compute, so `origin.dev-cool.click` resolves to nothing: `/api/*` and `/ws` return CloudFront 502 (`edge/cloudfront.tf:1-4`), and P2-T05's migrate task has nowhere to run → M1 blocked.
**Value:** the last layer of CloudFront → ALB → ECS → Aurora. It proves secrets, health checks, Aurora resume and WS through CF/ALB by hand before a pipeline hides them → M1. Unblocks P2-T08 (deploy target), P2-T09 (hibernate destroys `app`), P4 (WS-metric scaling), P6 worker (same module), P7 sidecar.

## Concepts
- **Execution vs task role:** without: secrets go on the task role → the agent can't resolve the task-def `secrets` → `ResourceInitializationError`. With: the execution role reads `devcool/dev/jwt-*` + `rds!cluster-…` (exact ARN from SSM `db_master_secret_arn`, which RDS names, so no prefix matches it); the task role gets S3 media only. Read: ref 07 Self-check 2; P2-T05 brief.
- **Driver vs pool timeouts:** without: Aurora resumes in ≥ 30 s, but pgjdbc gives up at 10 s (`connectTimeout`) / 5 s (`sslResponseTimeout`), and Hikari fails fast at startup → migrate and api crash-loop. With: `?connectTimeout=60&sslResponseTimeout=60000` in `SPRING_DATASOURCE_URL`. Read: `application-ecs.properties:7`.
- **Origin verification:** without: any AWS customer's distribution passes the prefix-list SG (`network/security_groups.tf:35-42`) and reaches the API around our behaviours. With: edge sends `X-Origin-Verify`; the listener forwards only on a match, otherwise a fixed 403. Read: ADR-0011.
- **Stable alias + ignored task def:** without: the ALB DNS name changes on every resume, and Terraform reverts the pipeline's image. With: the `origin.<domain>` alias in `app`; `ignore_changes = [task_definition]`. Read: ADR-0013 → P2-T04; ADR-0003.

## Done when
1. Phase-2 smoke steps 1–5 pass: ECR push, `ecs,migrate` exit 0, targets healthy, `curl https://dev-cool.click/actuator/health` → 200 UP, `wscat -c wss://dev-cool.click/ws` reaches the app and is rejected.
2. `curl https://origin.dev-cool.click/actuator/health` without the header → 403 from the ALB.
3. The migrate task and api start against a paused cluster (0 ACU) without a crash loop.
4. The ECS/ALB values match the phase table (idle 120 s, readiness 10 s, dereg 30 s, `stopTimeout` 45 s, 100/200 + circuit breaker, 0.5 vCPU/1 GB, CPU 60%).
5. A second `plan` of `app` and `edge` → no changes; destroying and re-applying `app` touches neither `edge` nor `data`.
- **Out of scope:** pipeline, CI migrate step, circuit-breaker rollback test (P2-T08); env-power (P2-T09); WS allowlist code + tickets (P4-T06); connection-metric scaling (P4); worker/SQS (P6); OTel sidecar (P7); WAF (P9).
- **Tests:** CI infra job; `aws-architect` reviews each plan; checks 1–3 as a runnable checklist in the PR.
- **Files:** `infra/modules/ecs-service/*`, `infra/stacks/app/*`, `infra/stacks/edge/{cloudfront,ssm}.tf`, `infra/stacks/data/` (log group + SSM), `infra/stacks/bootstrap/oidc.tf` (#2, #3a, #3c, #10), `infra/README.md`, phase-2 tick + the task-role line.
- **Invariants:** tasks in private subnets with no public IP; HTTPS listener only (TLS 1.2+, edge cert); IAM uses specific actions on specific ARNs; every role is `devcool-*`, path `/`, with the bootstrap boundary (#2, #3d).
