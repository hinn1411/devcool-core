# P4-T01 — Safe per-session writes (decorator + cleanup)
P4 · mode B · Must · est 3–4 h · done · 2026-11-26

**Why:** writes hit the raw session (`FrameWriter`, `ChatHandler` actions) on the sender's thread (`SendMessageService.java:47`) → one stalled client delays the channel; concurrent writes garble frames (`learning/04` §2).
**Value:** Stage 1 hardening for the backplane (`learning/10` §7) → M2 slow-client drill. Unblocks T02, T08.

## Concepts
- **Serialized writes:** the decorator queues a 2nd concurrent write instead of `TEXT_PARTIAL_WRITING`.
- **Bounded buffer + TERMINATE:** past 512 KB / 5 s the decorator throws; we close with 4500, the client resumes (T09).
- **Decorator never closes itself:** the caller must catch `SessionLimitExceededException` and close (off-thread: Tomcat's close waits for the stuck writer).
- **Lock holder still blocks:** the time limit trips only on the next send; Tomcat `BLOCKING_SEND_TIMEOUT` bounds the stuck write.

## Done when
1. Sessions are stored wrapped (config limits, TERMINATE); every write goes through the wrapper.
2. Two concurrent writes to one session both arrive.
3. B's socket blocks → A and C still receive; B closes with 4500 on buffer or time limit.
4. No push failure escapes the fan-out loop; the failed session is closed.
5. A stuck native write fails after the 5 s Tomcat timeout.
6. Every exit (close, transport error, TERMINATE) cleans up; twice is a no-op; no subscribe after cleanup.
- **Out of scope:** NACK (T02), heartbeat (T03), drain (T14), serialize-once (T07), real slow-client IT (T16), node-wide memory cap (T13/T15).
- **Tests:** `SessionRegistryTest`, `SessionEmitterAdapterTest`, `FrameWriterTest`, `ChatHandlerTest`, `InMemoryConnectionRegistryAdapterTest`, `WsVirtualThreadsIT`.

## Decisions
| Question | Answer | Source |
|---|---|---|
| Close code on overflow | 4500; ADR-0005 amended | user |
| Bound the stuck write | Tomcat `BLOCKING_SEND_TIMEOUT` 5 s | user |
| Slow-consumer proof | Unit fakes now, real IT in T16 | user |
| Limits | `devcool.ws.send.*` (5 s, 512 KB) | `03-chat-system-design.md:157` |
| Close thread | Virtual thread, not the fan-out thread | review |
