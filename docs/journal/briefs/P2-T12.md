# P2-T12 — Deployment docs (README + docker/ecs)
P2 · mode C · Should · est 2 h · done · 2026-11-21

**Why:** `README.md:141-231` still documents the pre-P2 setup (public-subnet task, RDS t3.micro, `:latest` push + manual `update-service`, plain-value env vars). `docker/ecs/README.md` and `task-env.example` are empty → a reader (or interviewer) follows steps that no longer exist.
**Value:** closes the P2 docs gap so M1 ("a merge to master deploys automatically") is described where people look first. Makes it possible to reproduce ECS profile bugs locally before P4/P6 add Valkey and SNS/SQS env vars.

## Concepts
- **One source per fact:** without it, README repeats infra/README's runbook steps → the two drift on the next workflow change. With it, README gives the overview and links to `infra/README.md` for commands and gotchas (memory: runbooks hold the gotchas).
- **Prod image, local deps:** without it, an `ecs`-profile startup bug (datasource URL, Flyway off) only shows up after a deploy. With it, `docker run` of the built image with `SPRING_PROFILES_ACTIVE=ecs` against Compose Postgres fails in seconds. Read: `docs/references/10-spring-boot-and-java-runtime.md`.

## Done when
1. README "AWS Architecture" describes the real shape: CloudFront → ALB → ECS (2 tasks) → Aurora, plus S3 media, the SPA bucket, ECR, OIDC. It has no RDS t3.micro, public-subnet or `0.0.0.0/0:8080` text.
2. README "Deployment" names the flows: merge to master → `deploy.yml` (build → migrate → roll → smoke), infra PR → `infra-plan` → `infra-apply`, `env-power` modes. No `:latest` and no manual `update-service`. It links to `infra/README.md` for the steps.
3. The README env-var table matches `infra/stacks/app/service.tf:16-30` and marks which values are secrets (Secrets Manager ARNs).
4. `docker/ecs/README.md` runs the built image with the `ecs` profile against `docker/local` Postgres, with copy-pasteable commands. `task-env.example` lists those variables with placeholder values only.
- **Out of scope:** the Valkey/SNS/SQS env vars (P4, P6), the frontend deploy docs.
- **Tests:** follow `docker/ecs/README.md` from a clean checkout until `/actuator/health` returns 200. `grep -nE "latest|update-service|t3.micro" README.md` finds nothing. Every link in the changed sections resolves.
- **Files:** `README.md`, `docker/ecs/README.md`, `docker/ecs/task-env.example`
- **Invariants:** no real secrets in `task-env.example`; never read `local.env`.
