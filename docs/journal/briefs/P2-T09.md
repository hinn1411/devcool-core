# P2-T09 — env-power.yml (sleep/wake/hibernate/resume)
P2 · mode C · Must · est 10 · agreed · 2026-10-23

**Why:** the only way to cut cost today is by hand (`infra/README.md:48-90`). Awake bills ~$0.26/h (≈ $190/month), and ADR-0013 needs hibernated as the default plus a mandatory nightly hibernate. Without that, one forgotten window breaks the $20 budget (`infra/stacks/bootstrap/budget.tf`).
**Value:** P2 → M1 ("first window, then hibernated; cost/h measured"). Unblocks the postponed P2-T08 checks, P2-T12, every AWS window up to M5, and P4-T05 (adds Valkey to the guard).

## Concepts
- **Two depths of off:** without: there's only sleep, so the ALB, NAT and 8 endpoint-AZs keep billing ~$0.16/h ≈ $115/month. With: hibernate is the default (~$2.5/month), and sleep is a 2-minute pause inside a window. Read: ADR-0013 §Options.
- **Autoscaling min, not desired count:** without: `update-service --desired-count 0`, then the next `app` apply re-registers min 1 and a task comes back. With: apply `app` with `api_min_count=0` (`.github/scripts/terraform-stack.sh:252`). Read: ref 07 §Service auto scaling.
- **Guarded unattended apply:** without: the nightly hibernate applies `data` along with someone's other pending change, so an unreviewed change lands on the stack that holds Aurora. With: a saved plan plus a `terraform show -json` allowlist (empty until P4-T05) fails before applying; `prevent_destroy` (`infra/stacks/data/aurora.tf:54`) is the backstop. Read: ADR-0013 §Consequences.
- **Verify on resume:** without: a merge while hibernated registered a new revision (`deploy.yml:498`), so resume starts it against the old schema and it crash-loops. With: `app` at min 0, then migrate, then min 1, then the smoke test. Read: P2-T08 brief §Decisions.

## Done when
1. `sleep` → desired count 0 and autoscaling min 0, `https://<domain>/actuator/health` returns 503. `wake` → 200 within ~5 min.
2. `hibernate` → `/devcool/dev/app/*`, the NAT and the interface endpoints are gone, `edge` is untouched, health returns 502. A second `hibernate` is a no-op.
3. Any `data` change outside the allowlist → hibernate fails before the `data` apply.
4. `resume` after a merge while hibernated → migrate exits 0 (1 retry for a cold Aurora), service stable, smoke 200. Every stack re-plans "No changes".
5. `sleep`/`wake` on a hibernated env fail with "use resume"; the nightly `hibernate` runs at 17:00 UTC; bootstrap trusts `env-power.yml` with 7200 s sessions (review #8, applied by hand).
6. `infra-apply` converges: it plans every stack and applies the ones with changes, so a cancelled run loses nothing.
7. Right after the first resume, the 5 postponed P2-T08 checks pass (phase 2, P2-T09 carry-over).
8. `infra/README.md` has a cost table per state, with the measured $/h added after the window (M1 gate).
- **Out of scope:** Valkey toggle (P4-T05), WS drain 1006 vs 1012 (P4), README "Deployment" (P2-T12), prod (ADR-0013).
- **Tests:** each mode once by `workflow_dispatch` + curl status; `hibernate` twice; a deliberate `data` change → the guard fails; a merge while hibernated → resume verifies; a cancelled `infra-apply` → the next run still applies its stack.
- **Files:** `.github/workflows/{env-power,infra-apply}.yml`, `.github/scripts/{terraform-stack,run-migrate-task,wait-for-health}.sh`, `infra/stacks/bootstrap/{variables,oidc}.tf`, `infra/README.md`, phase 2.
- **Invariants:** OIDC `gha-deploy` in `aws-deploy`; `concurrency: aws-dev`, no cancel-in-progress; never touches `bootstrap`/`edge`; Aurora and media are never destroyed; actions pinned to a SHA.

## Decisions
| Question | Answer | Source |
|---|---|---|
| Hibernate and resume order | destroy `app` → `data` (guarded) → `network` toggles off; resume reverses it; `edge` untouched | ADR-0013 |
| Does wake migrate? | No: a deploy while asleep already migrated and rolled out at 0 tasks | P2-T08 brief, `deploy.yml:505` |
| Sleep/wake mechanism | Terraform `app` apply with a state override (min and count together, no drift) | user, 2026-10-23 |
| Nightly hibernate | 17:00 UTC | user, 2026-10-23 |
| `infra-apply` converge | In this task: env-power joins `aws-dev`, so more pending runs get cancelled | user, 2026-10-23 |
| Sleep/wake while hibernated | Fail with "use resume" | user, 2026-10-23 |
