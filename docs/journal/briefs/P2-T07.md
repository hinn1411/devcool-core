# P2-T07 — `edge` stack: CloudFront, SPA bucket, ACM, Route 53
P2 · mode C · Must (promoted from Should) · est 5h + DNS wait · agreed · 2026-10-18

**Why:** `infra/stacks/edge` doesn't exist; P2-T04's HTTPS listener and `origin.<domain>` alias need its zone + cert (ADR-0013 apply order data → **edge** → app). Without it, P2-T04's smoke test (steps 4–5) and `deploy.yml`'s health check (P2-T08) have no URL.
**Value:** ADR-0011's single origin (no CORS, `SameSite=Strict` refresh cookie) → P2 "CloudFront → ALB → ECS" → M1. Unblocks P2-T04, P2-T08, P5-T14 (S3 sync + invalidation).

## Concepts
- **Stable origin name:** without: CloudFront origin = ALB DNS name → every hibernate/resume recreates the ALB, the name changes, `edge` must change. With: origin = `origin.<domain>`; `app` repoints the alias, `edge` never changes. Read: ADR-0013 Consequences → P2-T04.
- **Cache vs origin request policy:** without: default behaviour on `/api/*` caches and strips `Authorization`, cookies, `?ticket=` → 401s, WS upgrade fails. With: `CachingDisabled` + `AllViewerExceptHostHeader` (Host not forwarded, so TLS to the ALB matches `origin.<domain>`). Read: ADR-0011 §3; ref 07 Self-check.
- **ACM DNS validation needs the delegated zone:** without: a new `aws_route53_zone` gets different NS than the registrar's → validation CNAMEs land in an unresolved zone → `aws_acm_certificate_validation` hangs. With: import the live zone (`Z08037022ZW7LDOE7CIOE`, NS already delegated), cert issues in minutes. Read: ref 07 § CloudFront, ACM, Route 53.
- **Custom error responses are distribution-wide:** without: 404→`/index.html` or 502→"asleep" also turns `/api/*` JSON errors into HTML. With: none on this distribution; SPA routing via a CloudFront Function on the default behaviour (P5). Read: ref 07 Custom error responses.
