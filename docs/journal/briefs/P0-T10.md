# P0-T10 — Install local binaries used by the config
P0 · mode C · Must · est 45 min · done · 2026-09-30

**Why:** `.claude/settings.json` enables `jdtls-lsp`/`typescript-lsp`, whose servers weren't on `PATH`, and `.claude/hooks/format-other.sh:17` skips `.tf` files when `terraform` is missing → P0-T11 `/doctor` fails, Claude navigates by grep, and P2 starts without its prerequisites.
**Value:** P0 goal (faster, safer daily work) → P1/P3 symbol navigation and P2 infra → M1. Unblocks P0-T11, P2-T01…T10, P5 LSP.

## Concepts
- **The config names a binary, it doesn't ship it:** without: `jdtls` missing → the plugin can't start it → Claude greps for `MembershipPort` and misses usages. With: find-references by symbol. Read: ref 16 → Plugins overview.
- **A check that fails open skips work silently:** without: `format-other.sh` exits 0 with no `terraform` → CI's `fmt -check` fails later. With: the `.tf` file is formatted on edit. Read: ref 16 → hooks.
- **The launcher's `PATH` matters:** without: `nvm use 24` drops the global `typescript-language-server` → the LSP fails. With: verify from Claude's Bash tool; reinstall after switching Node. Read: ref 16 → Debug your configuration.
- **The version floor comes from an ADR:** without: TF 1.10 → `use_lockfile` (ADR-0003) is experimental. With: ≥ 1.11 (GA), pinned per P2 stack. Read: ref 08 → Backend type: s3.
