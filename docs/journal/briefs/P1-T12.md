## Concepts
- **Real token:** without: `.with(user("7"))` passes with a stale-version token. With: a real `/login` token goes through `JwtAuthFilter`'s version check. `learning/12` §8
- **Seed the excluded rows:** without: a one-channel cursor test passes with no `channel_id` filter. With: other-channel and soft-deleted rows seeded between the included ids. `learning/12` §7
- **MockMvc isn't a browser:** without: the `Path=/api/v1/auth/refresh` bug passes, because MockMvc ignores Path. With: the raw `Set-Cookie` attributes are asserted. `learning/12` §8
- **Commit, don't roll back:** without: a `@Transactional` flow hides failures at commit time. With: each request commits, and the tables are truncated in `@BeforeEach`. `learning/12` §6
