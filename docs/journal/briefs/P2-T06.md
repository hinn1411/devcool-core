# P2-T06 — Production Dockerfile + CI image check
P2 · mode C · Must · est 2 h · done · 2026-10-15

**Why:** `Dockerfile:9-13` runs as root, leaves the JVM heap at its 25% default (~256 MB of the 1 GB task), ships one fat-jar layer, uses unpinned tags, and no CI job covers it (`ci-changes.yml:36`). P2-T08 would deploy exactly this image.
**Value:** P2-T06 → the artifact behind M1 ("a merge deploys to dev"). Unblocks P2-T08 (build/scan/push), P2-T04 (task-def `memory`/`stopTimeout` assume java is PID 1), P7-T06 (OTel agent).

## Concepts
- **Container-aware heap:** without: 1 GB task → 256 MB heap, OOM under WS load with ~700 MB idle. With: `MaxRAMPercentage=75` → ~768 MB; `ExitOnOutOfMemoryError` lets ECS replace the task. Read: `docs/learning/18-docker-and-ecs.md` §3.4.
- **Layered jar:** without: a one-line fix pushes a new ~80 MB layer to ECR. With: only `application` (~1 MB) changes; use `-Djarmode=tools`, not `layertools`. Read: ch18 §2.5.
- **Non-root + PID 1:** without: a media-upload file-write bug runs as UID 0; shell-form `ENTRYPOINT` loses SIGTERM → SIGKILL drops WebSockets. With: `USER app` + exec form → graceful 30 s shutdown. Read: ch18 §3.2–3.3.
- **Build context:** without `.dockerignore`: a future `COPY . .` bakes `local.env` (JWT secrets) into ECR. With an allow-list: only `pom.xml`, `mvnw`, `.mvn`, `src`. Read: ch18 §2.2.

## Done when
1. Given the image, when inspected, then `Config.User` is numeric non-root (`10001:10001`) and `id -u` in the container ≠ 0.
2. Given `docker run -m 1g`, when the JVM starts, then it logs `Picked up JAVA_TOOL_OPTIONS` and `MaxHeapSize` ≈ 768 MB.
3. Given a `src`-only change, when rebuilt, then dependency layers are `CACHED` and `docker history` shows the 4 Boot layers.
4. Given a running container (local profile + compose Postgres), when `docker stop`, then Spring logs graceful shutdown and exit code is 143, not 137.
5. Given a PR touching only `Dockerfile`, then `docker / Build, lint and scan image` runs (hadolint + Trivy OS gate pass) and it's in `ci-gate`'s `needs`.
6. `.github/dependabot.yml` bumps the pinned base-image digests weekly.
- **Out of scope:** ECR push, deploy, deploy-time scan (P2-T08); container `memory`, `stopTimeout`, `readonlyRootFilesystem` (P2-T04); OTel agent (P7-T06); arm64 (budget ADR).
- **Tests:** 1–3 as CI steps (`docker inspect`, `docker run --entrypoint`); 4 as a one-off manual run.
- **Files:** `Dockerfile`, `.dockerignore`, `.github/workflows/ci-docker.yml` (new), `ci.yml`, `ci-changes.yml`, `.github/dependabot.yml` (new), phase file.
- **Invariants:** exec-form `ENTRYPOINT`; last `USER` non-root; no secrets in the build context; P7-T06 must *append* to `JAVA_TOOL_OPTIONS` (a task-def override replaces the whole variable).
