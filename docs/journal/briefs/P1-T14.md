# P1-T14 — CI that fails when something is wrong
P1 · mode C · Must · est 5h · agreed · 2026-10-08

**Why:** CI goes green while checking almost nothing: `ci.yml:55` ends static analysis with `|| true`, `ci.yml:58` skips every IT (`-DskipITs`, and Failsafe only runs under `-Dit`), `ci.yml:60` never runs Sonar, and `on: push` has no `pull_request` trigger ([learning/06](../../learning/06-testing-and-verification.md) §2–3).
**Value:** meets P1's Definition of Done ("CI runs unit + IT + static analysis and fails on any of them"). Turns P1-T12 (authz ITs) and P1-T13 (ArchUnit) into PR gates before P2-T08 deploys from this pipeline.

## Concepts
- **Gate states:** without: `|| true` shows green while 109 SpotBugs findings, including the public session map (`WsSessionStore.java:11`), go unseen. With: the step's exit code fails the job. Read: learning/06 §2.
- **Vacuous pass:** without: PMD 6.55 can't parse Java 21, logs 207 processing errors with 0 violations, and is green; a step that runs 0 ITs is green too. With: assert that something ran (`Tests run: 66`). Read: ref 09, "Quality gates".
- **Ratchet:** without: fix all 104 `EI_EXPOSE_REP*` findings now (days) or suppress them all (signal lost). With: baseline today's findings, fail on anything new, burn the baseline down. Applies to coverage too. Read: learning/06 §2.
- **Cache key = image identity:** without: a cached `pg16` tag is silently a different image from Friday's pull. With: pin the digest, then cache by digest.

## Done when
1. A push to `master` or any PR runs spotless, then SpotBugs, then unit + IT + coverage check; any failure turns the job red.
2. CI logs show 66 ITs run, not 0. Sonar runs on every run, without a second test run.
3. Each gate is proven to fail: one throwaway commit per gate (format, SpotBugs, a unit test, an IT, coverage) goes red, then is reverted. The PR lists the red run links.
4. The 5 non-EI findings are fixed: `WsSessionStore:11`, `RawWebSocketHandler:49`, `TokenIssuerAdapter:47`, `MediaService:130`, `LogoutResponse:8`.
- **Out of scope:** making models immutable to clear the EI baseline (new task). Re-adding PMD 7 with a curated ruleset (new Could task). Path filters and OIDC (P2).
- **Tests:** the red/green runs in criterion 3. Unit tests for the 5 fixes where behaviour changes (e.g. `MediaService` extension case under a Turkish locale).
- **Files:** `.github/workflows/ci.yml`, `pom.xml` (remove Checkstyle and PMD; SpotBugs `excludeFilterFile`; JaCoCo `check`), `spotbugs-exclude.xml`, `src/test/java/com/devcool/support/PostgresTestContainer.java` (digest), the 5 source files, `CLAUDE.md` CI section.

| JaCoCo threshold | `check` on line coverage. Floor = the first green CI run's line coverage (unit + IT), rounded down to 5%, then ratchet up. Measured 75.4% locally → floor 0.75 (`jacoco.line.minimum`), checked only under `-Dit` | user, ratchet principle, impl |

## Prediction gaps
- (a) `|| true` → right, and the ITs and Sonar are dead too, for different reasons (`ci.yml:58`, `:60`). *knowledge gap*: learning/06 §3.
- (b) "IT runs" → it must be *shown* to run (66, not 0). PMD also passes today with nothing analysed. *knowledge gap*: ref 09, "Quality gates".
- (c) "red now, fix → green" → add the reverse: after the fix, a planted violation must still go red, or "green" proves nothing (criterion 3). *knowledge gap*: learning/06 §2.
- (d) 1h → about 5h: the 5 fixes, the baseline file, JaCoCo/Sonar, and one push-and-wait per gate proof. *knowledge gap*.
