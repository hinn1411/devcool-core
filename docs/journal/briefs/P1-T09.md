# P1-T09 — Require a token on `/api/v1/channels` and answer 401
P1 · mode A · Must · est 2.5 h · agreed · 2026-10-02

**Why:** `/api/v1/channels` is in `permitAll` (`SecurityConfig.java:42`), so an anonymous `POST` or `GET` reaches `ChannelController.java:42` and `:88`, fails on `auth.getName()` and returns 500 (`learning/02` §7). `/api/v1/auth/logout` (`:38`) has the same bug.
**Value:** closes the "+ `permitAll`" audit row → P1 Definition of Done. Gives P1-T12 a security-enabled test pattern to extend; P5's SPA needs a real 401 to trigger its refresh flow.

## Concepts
- **`permitAll` is an allowlist, not a bypass:** without: the entry lets an anonymous request pass the authorization rule, and the controller crashes. With: the request falls to `anyRequest().authenticated()` and is rejected before the controller. Read: `learning/02` §7.
- **401 needs an entry point:** without: `SecurityConfig` sets none, so Spring's default answers an anonymous call with 403, and the SPA can't tell "log in" from "not allowed". With: an entry point returns 401 in the standard envelope. Read: `11-security.md` §Concepts.
- **A test must run the filter chain to see it:** without: every slice uses `addFilters = false`, so removing the entry changes no test result. With: a slice that imports `SecurityConfig` with filters on. Read: `learning/07`.

## Done when
1. Given no `Authorization` header, `GET` and `POST /api/v1/channels` and `POST /api/v1/auth/logout` return 401 and no use case is called.
2. The 401 body is an `ApiErrorResponse` with a new `ErrorCode` for "unauthenticated", mapped in `HttpErrorMapper`.
3. Given a valid principal, the three endpoints still reach their controllers.
4. `/api/v1/channels` and `/api/v1/auth/logout` are gone from `permitAll`; every remaining entry has a one-line reason.
5. Register, login and refresh stay reachable without a token.
- **Out of scope:** real-token authz ITs (P1-T12); `/ws` staying public until tickets (ADR-0011, P4); a custom 403 handler for authenticated-but-forbidden; removing the unused `/public/**` entry.
- **Tests:** a new security slice (`@WebMvcTest` + `@Import(SecurityConfig.class)`, filters on): no token → 401 with the envelope on the three endpoints; `with(user("7"))` → not 401; login without a token → not 401. `HttpErrorMapperTest` row for the new code.
- **Files:** `SecurityConfig`, a new entry-point class in `adapters/in/web/security/`, `ErrorCode`, `HttpErrorMapper`, the new test class, `HttpErrorMapperTest`, phase file checkbox.
- **Invariants / authz:** no protected endpoint answers an anonymous caller with 500 or 403; the entry point never echoes the `Authorization` header.
