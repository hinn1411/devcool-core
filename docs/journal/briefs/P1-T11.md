## Concepts
- **Singleton container:** one container per JVM; a per-class container changes the port and breaks the context cache. `learning/12` §3.
- **Context cache:** config only on the base class; each `@MockitoBean` in a subclass adds a context. `learning/12` §4.
- **Failsafe:** `*IT` runs only with `./mvnw -Dit verify`. `learning/12` §2.
- **Test config:** `application-test.properties`; a test `application.properties` would replace the main one. `learning/12` §4.

## Done when
1. `DevCoolApplicationIT` boots with no env vars: Flyway V1 + V2 succeeded, the V2 index exists, `vector` is available.
2. `./mvnw test` starts no container.
3. One container serves `AbstractIntegrationTest` and `AbstractJpaIT`.
- **Out of scope:** real ITs and DB cleanup (P1-T12), CI (P1-T14), `CREATE EXTENSION vector` (P8-T01).
